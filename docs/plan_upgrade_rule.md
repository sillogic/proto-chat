# 订阅方案设计文档

## 1. 方案概览

| 方案  | 等级 | 说明                         |
| ----- | ---- | ---------------------------- |
| Free  | 0    | 默认方案，用户初始化时自动分配 |
| Lite  | 1    | 入门付费方案                 |
| Pro   | 2    | 中档付费方案                 |
| Ultra | 3    | 高级付费方案                 |

## 2. 付费周期

三种付费方案均支持以下付费周期：

| 周期类型           | 优先级 | Tab 标签   | 订阅类型 |
| ------------------ | ------ | ---------- | -------- |
| 一次性付费（1个月）  | 1      | 一次性付费 | 一次性   |
| 连续包月           | 2      | 连续包月   | 循环订阅 |
| 一次性付费（3个月）  | 3      | 一次性付费 | 一次性   |
| 一次性付费（6个月）  | 4      | 一次性付费 | 一次性   |
| 一次性付费（12个月） | 5      | 一次性付费 | 一次性   |
| 连续包年           | 6      | 连续包年   | 循环订阅 |

**支付方式：** 支付宝、微信

## 3. 方案等级判定规则

**等级计算公式：**

```
方案等级 = 方案类型等级 × 100 + 付费周期优先级
```

**判定原则：**

- 方案类型是决定性因素，方案类型高则等级高
- 同方案类型下，按付费周期优先级判定

**示例：**

| 方案              | 计算      | 等级值 |
| ----------------- | --------- | ------ |
| Lite 一次性(1月)  | 1×100+1   | 101    |
| Lite 连续包月     | 1×100+2   | 102    |
| Pro 一次性(1月)   | 2×100+1   | 201    |
| Pro 连续包年      | 2×100+6   | 206    |

所以：`Lite 连续包月(102) < Pro 一次性1月(201)`

## 4. 升级规则

- **只允许升级，不允许降级**
- 升级后立即生效
- 升级价格 = 新方案价格 - 优惠金额 - 当前方案残值

## 5. 残值计算规则

**统一公式：** `残值 = 实付金额 / 订阅周期天数 × 剩余天数`

| 周期类型   | 计算方式                          |
| ---------- | --------------------------------- |
| 连续包月   | 当期实付金额 / 30 × 剩余天数      |
| 连续包年   | 实付金额 / 365 × 剩余天数         |
| 一次性付费 | 实付金额 / 月数 / 30 × 剩余天数   |

**说明：**

- 每月固定按 30 天计算
- 日均价格保留两位小数，向上取整
- 按实付价格计算，非原价
- Free 方案无残值

**示例：**
一次性付费 3 个月 Lite，实付 447 元，剩余 12 天

- 日均价格 = 447 / 3 / 30 = 4.97（向上取整）
- 残值 = 4.97 × 12 = 59.64 元

## 6. 积分发放规则

**通用规则：**

- 按月发放积分
- 发放时积分重置（不累积）

**发放时机：**

- 以最新方案订阅日期为准，每月该日 00:00:00 发放
- 例：1月15日订阅/升级，则每月15日0点发放积分

**发放数量：**

- 根据当前生效方案决定发放数量

## 7. 方案到期与降级机制

### 7.1 一次性付费方案

- 到期后自动变为 Free 方案

### 7.2 循环订阅方案

- 正常续费：自动扣款，延续当前方案
- 扣款失败：自动降级为 Free 方案

### 7.3 降级为 Free 的处理逻辑

无论是到期降级还是扣款失败降级，系统均按「用户新订阅 Free 方案」逻辑处理：

1. 方案变更为 Free
2. 立即发放 Free 方案积分
3. 设定新的积分重置时间（降级当日为每月发放日）

## 8. 订阅状态流转

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  用户注册 ──→ Free ←──────────────────────────┐        │
│               │                               │        │
│               │ (付费)                        │        │
│               ↓                               │        │
│            Active ──→ (升级) ──→ Active      │        │
│          (付费方案)            (更高方案)     │        │
│               │                    │          │        │
│               │                    │          │        │
│               ├────────────────────┘          │        │
│               │                               │        │
│               │ (一次性到期 / 循环扣款失败)    │        │
│               └───────────────────────────────┘        │
│                                                         │
│  Free 方案：按月自动重置积分，无需续费                   │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 9. 不支持的功能

- ❌ 方案降级
- ❌ 退款
- ❌ 试用期（Free 方案除外）

# 前端改造需求

## 10. 订阅方案页面 - 方案卡片按钮

| 场景             | 按钮文字 | 状态                                                           |
| ---------------- | -------- | -------------------------------------------------------------- |
| 当前方案         | 我的订阅 | 不可点击                                                       |
| 比当前等级高     | 订阅升级 | 可点击，点击打开「订阅升级弹窗」                               |
| 比当前等级低或同级 | 订阅     | 不可点击，hover 提示："您已开通同级或更高等级订阅，无需再订阅此套餐" |

## 11. 订阅升级弹窗

### 11.1 弹窗结构

```
┌─────────────────────────────────────────────────────────────┐
│ 订阅升级                                              [X]  │
├─────────────────────────────────────────────────────────────┤
│ ┌─────────────────────┐    ┌─────────────────────────────┐ │
│ │ {现有方案名} [现有套餐] │ → │ {新方案名}        [购买中] │ │
│ │ {周期类型}            │    │ {周期类型}                 │ │
│ │ 失效时间：订阅升级后失效 │    │ 生效时间：升级后立即生效    │ │
│ └─────────────────────┘    └─────────────────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│ 新套餐原价                                      ¥{原价}    │
│ 优惠活动                        [{活动标签}]  -¥{优惠金额} │
│ 现有套餐剩余价值                          (i) -¥{残值}    │
│ 套餐差价 ∧                                     ¥{差价}    │
│ ─────────────────────────────────────────────────────────  │
│ 实付金额                                       ¥{实付}    │
├─────────────────────────────────────────────────────────────┤
│ ┌─────────┐  请使用{支付方式}扫码支付 ¥{实付}              │
│ │         │                            [切换{另一支付方式}] │
│ │ 二维码   │                                               │
│ │         │  • {循环订阅提示1}                             │
│ │         │  • {循环订阅提示2}                             │
│ └─────────┘  • {循环订阅提示3}                             │
│              • {循环订阅提示4}                             │
├─────────────────────────────────────────────────────────────┤
│ 支付即视您同意《服务协议》《订阅协议》，虚拟商品一经支付不支持退款 │
└─────────────────────────────────────────────────────────────┘
```

### 11.2 字段说明

| 字段               | 说明                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| 现有方案名         | 当前订阅的方案名称，如 "Lite"                                        |
| 新方案名           | 要升级到的方案名称，如 "Pro"                                         |
| 周期类型           | 显示付费周期，如 "包月计划"、"包季计划"、"包年计划"                   |
| 新套餐原价         | 新方案的原始价格                                                     |
| 优惠活动           | 如有优惠则显示，标签如 "首购5折"，无优惠则隐藏此行                    |
| 现有套餐剩余价值   | 残值，点击 (i) 图标显示计算说明                                       |
| 套餐差价           | 可展开/收起，展开显示计算明细                                         |
| 实付金额           | 最终需要支付的金额 = 原价 - 优惠 - 残值                               |

### 11.3 循环订阅特有提示

当新方案为循环订阅时，显示以下提示：

- 续订将按照「¥{月/年费}/月」发起自动扣费。
- 扣费优先级：优先扣除赠金，再扣余额，再采用{当前支付方式}扣费。
- 每月将持续定期扣款，直至您根据我们的服务条款取消服务。
- 您可在续费日前至少1天，前往「我的编程套餐」关闭自动续费。

### 11.4 一次性付费提示

当新方案为一次性付费时，显示以下提示：

- 本次为一次性付费，到期后将自动降级为免费版。
- 到期前可随时升级至更高方案。
