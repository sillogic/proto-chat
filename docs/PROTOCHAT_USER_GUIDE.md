# ProtoChat 用户使用指南

## 什么是 ProtoChat？

ProtoChat 是系统内置的 AI 服务供应商，为您提供多种主流 AI 模型。与其他需要自己配置 API Key 的服务商不同，ProtoChat 由系统管理员统一配置和管理，您只需启用即可直接使用，并按积分消耗计费。

### 主要特点

✅ **无需配置** - 不需要自己申请和配置 API Key
✅ **积分计费** - 按实际使用的 token 数量消耗积分
✅ **多模型选择** - 提供多种主流 AI 模型（GPT、Claude、DeepSeek 等）
✅ **按需启用** - 可以选择启用自己需要的模型
✅ **独立配置** - 您的配置不影响其他用户

---

## 如何使用 ProtoChat？

### 步骤 1: 启用 ProtoChat 服务

1. 点击右上角头像，选择 **"设置"**
2. 进入 **"语言模型"** 选项卡
3. 在服务商列表中找到 **"ProtoChat AI"**（通常在列表最前面）
4. 点击右侧的开关，启用 ProtoChat

![启用 ProtoChat](./images/protochat-enable.png)

> **提示**: ProtoChat 不会显示 API Key 配置项，因为它是由系统管理员统一配置的。

---

### 步骤 2: 选择要使用的模型

1. 点击 **ProtoChat AI** 卡片，进入模型配置页面
2. 查看可用的模型列表
3. 勾选您想要使用的模型

![选择模型](./images/protochat-select-models.png)

**模型说明:**
- 每个模型有不同的能力和定价
- 您可以选择多个模型
- 模型名称格式: `ProtoChat::GPT-4o`, `ProtoChat::DeepSeek Chat` 等

> **注意**: 只有您启用的模型才会出现在对话窗口的模型选择器中。

---

### 步骤 3: 在对话中使用 ProtoChat 模型

1. 创建新对话或打开现有对话
2. 点击对话框顶部的模型选择器
3. 在 **"ProtoChat AI"** 分组下选择一个模型
4. 开始对话

![选择对话模型](./images/protochat-chat-model.png)

> **提示**: 不同的模型有不同的特点，您可以根据需要切换模型。

---

## 积分消耗说明

### 计费方式

使用 ProtoChat 模型会消耗您的积分。积分消耗按以下方式计算：

```
总费用 = (输入 tokens / 1,000,000) × 输入价格 +
         (输出 tokens / 1,000,000) × 输出价格
```

### 查看模型定价

1. 进入 **设置 → 语言模型**
2. 点击 ProtoChat AI 卡片
3. 查看每个模型的定价信息

不同模型的定价不同：
- **免费模型**: 不消耗积分
- **付费模型**: 按 token 数量消耗积分

### 查看消耗记录

您可以在 **"积分记录"** 页面查看每次对话的积分消耗详情。

## 常见问题

### 1. 为什么看不到 ProtoChat？

**可能原因:**
- 系统管理员未启用 ProtoChat 服务
- 您没有权限使用 ProtoChat
- 网络连接问题

**解决方法:**
- 联系系统管理员确认 ProtoChat 是否已启用
- 刷新页面重试

### 2. 为什么有些模型不能使用？

**可能原因:**
- 您未启用该模型
- 系统管理员未配置该模型
- 该模型暂时不可用

**解决方法:**
- 进入设置，检查模型是否已启用
- 联系系统管理员确认模型状态

### 3. 模型回复失败怎么办？

**可能原因:**
- 积分不足
- 模型服务暂时不可用
- 网络连接问题

**解决方法:**
- 检查积分余额，充值积分
- 切换到其他模型重试
- 刷新页面或稍后再试

### 4. 如何节省积分？

**建议:**
- 选择性价比高的模型（如 DeepSeek）
- 精简提示词，减少输入 tokens
- 使用免费模型（如果可用）
- 避免重复相同的问题

### 5. 我的模型配置会影响其他用户吗？

**不会**。每个用户的模型配置是独立的：
- 您启用/禁用模型只影响您自己
- 其他用户看不到您的配置
- 您也看不到其他用户的配置

## 最佳实践

### 1. 选择合适的模型

- **一般对话**: DeepSeek Chat (性价比高)
- **复杂推理**: GPT-4o, Claude Sonnet
- **代码生成**: DeepSeek Coder, GPT-4o
- **快速响应**: GPT-3.5 Turbo

### 2. 优化提示词

- 简洁明了的提问
- 避免冗余信息
- 必要时分步提问

### 3. 管理对话历史

- 定期清理不需要的对话
- 长对话会消耗更多 tokens
- 使用新对话开始新话题
