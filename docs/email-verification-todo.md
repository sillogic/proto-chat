## 🔲 待完成任务

### 任务 1：在钉钉后台创建系统邮箱

**目标：** 创建专门用于发送系统邮件的邮箱账号

**步骤：**
1. 登录钉钉管理后台
2. 进入 **工作台** → **邮箱** → **企业邮箱管理**
3. 创建新邮箱：
   - 邮箱地址：`noreply@your-domain.com`（或 `system@your-domain.com`）
   - 显示名称：ProtoChat 系统
   - 设置密码并**记录下来**

**完成标志：** ✅ 邮箱创建成功，密码已记录

---

### 任务 2：开启 SMTP 服务

**目标：** 允许程序通过 SMTP 发送邮件

**方法 A：在钉钉管理后台**
- 邮箱管理 → 邮箱设置 → 客户端设置
- 确保 SMTP 服务已开启

**方法 B：登录网页版邮箱**
1. 访问：https://qiye.aliyun.com/
2. 用新创建的邮箱登录
3. 右上角设置 → 客户端设置
4. 开启 **POP3/SMTP 服务**

**完成标志：** ✅ SMTP 服务已开启

---

### 任务 3：配置环境变量

**目标：** 在 `.env` 文件中添加邮件服务配置

**需要添加的配置：**

```env
# ===== 启用邮箱验证 =====
NEXT_PUBLIC_AUTH_EMAIL_VERIFICATION=1

# ===== 邮件服务配置（钉钉企业邮箱）=====
EMAIL_SERVICE_PROVIDER=nodemailer

# 钉钉企业邮箱 SMTP 服务器
SMTP_HOST=smtp.qiye.aliyun.com
SMTP_PORT=465
SMTP_SECURE=true

# 企业邮箱账号（请替换为实际账号和密码）
SMTP_USER=noreply@your-domain.com
SMTP_PASS=your-password-here

# ===== Auth URL 配置 =====
# 本地开发环境
NEXT_PUBLIC_AUTH_URL=http://localhost:3010
```

**操作步骤：**
1. 找到项目根目录的 `.env` 文件（如果不存在，复制 `.env.example` 并重命名）
2. 将上述配置添加到文件中
3. 替换 `SMTP_USER` 为实际的邮箱地址
4. 替换 `SMTP_PASS` 为实际的邮箱密码

**完成标志：** ✅ `.env` 文件已更新

### 任务 5：测试邮箱验证功能

**测试步骤：**

1. **打开浏览器**
   - 访问：http://localhost:3010

2. **注册新账号**
   - 点击"注册"按钮
   - 填写测试邮箱（使用你能收到邮件的真实邮箱）
   - 填写密码
   - 提交注册

3. **检查邮件**
   - 打开注册时填写的邮箱
   - 查找标题为 **"验证你的邮箱地址"** 的邮件
   - 如果在收件箱中没找到，检查垃圾邮件文件夹

4. **点击验证链接**
   - 点击邮件中的"验证邮箱"按钮
   - 应该自动跳转到应用并登录

5. **验证结果**
   - 检查是否成功登录
   - 用户状态显示为已验证

**完成标志：** ✅ 收到邮件并成功验证

## ⚠️ 常见问题处理

### 问题 1：没有收到邮件

**检查清单：**
- [ ] SMTP 服务已在钉钉后台开启
- [ ] `.env` 中的邮箱地址和密码正确
- [ ] 检查服务器日志是否有错误信息
- [ ] 检查垃圾邮件文件夹

**调试命令：**
```bash
# 查看服务器日志输出
# 注意观察是否有 [EmailService] 相关的错误
```

### 问题 2：SMTP 认证失败

**可能原因：**
1. 密码错误
2. SMTP 服务未开启
3. 需要使用"授权码"而不是密码

**解决方法：**
1. 重新确认密码
2. 尝试在邮箱客户端（如 Foxmail）测试 SMTP 连接
3. 如果钉钉要求使用授权码，在邮箱设置中生成

### 问题 3：端口连接失败

**备选方案：**
```env
# 如果端口 465 不通，尝试端口 25
SMTP_PORT=25
SMTP_SECURE=false
```
