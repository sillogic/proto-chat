# 后台系统支付相关页面优化

## 问题总结

### 1. 订阅记录金额显示错误 ❌

**问题描述：** 599元显示为5.99元

**根本原因：** 双重除以100
- 后端API在SQL查询中已经 `/ 100.0` 转换为元
- 前端页面再次 `/ 100` 转换

**影响：** 所有订阅记录的价格都错误地显示为实际价格的1/100

### 2. 支付订单缺少套餐价值信息

**问题描述：** 后台只显示实付金额，无法看到套餐原价和折扣情况

**影响：** 管理员无法直观了解订单的折扣信息和残值抵扣情况

## 修复内容

### 1. 修复订阅记录金额显示错误

#### 后端修改 (`admin-system/server/src/routes/subscriptions.ts`)

**修改前：**
```sql
h.price / 100.0 as price
```

**修改后：**
```sql
h.price,
h.billing_interval as "billingInterval"
```

**说明：**
- 删除了 SQL 中的 `/ 100.0`，保持返回分为单位
- 添加了 `billingInterval` 字段，与前端页面需要的数据一致
- 前端页面已有 `/ 100` 转换逻辑，无需修改

### 2. 优化支付订单页面，添加套餐价值显示

#### 后端修改 (`admin-system/server/src/routes/payments.ts`)

**订单列表API - 添加 `planValue` 字段：**
```sql
po.plan_value as "planValue"
```

**订单详情API - 添加 `planValue` 字段：**
```sql
po.plan_value as "planValue"
```

#### 前端修改 (`admin-system/src/pages/Payments/Orders/index.tsx`)

**1. 更新接口定义：**
```typescript
interface PaymentOrder {
  // ... 其他字段
  amount: number;
  planValue?: number;  // 新增
  // ... 其他字段

```

**2. 添加"套餐价值"列：**
- 显示套餐标准价值（原价 - 促销优惠，不含残值）
- 计算并显示节省金额
- 添加 tooltip 说明

**3. 优化"支付金额"列：**
- 重命名为"实付金额"
- 添加 tooltip 说明（已扣除促销优惠和残值）

## 数据单位标准化

### 统一规范

所有金额相关的字段在**数据库**和**后端API**中统一使用**分（cents）**为单位：

| 字段 | 单位 | 说明 |
|------|------|------|
| `payment_orders.amount` | 分 | 实付金额 |
| `payment_orders.plan_value` | 分 | 套餐价值 |
| `user_subscription_history.price` | 分 | 订阅价格 |
| `subscription_plans.monthly_price` | 分 | 月付价格 |
| `subscription_plans.yearly_price` | 分 | 年付价格 |

**前端展示规则：**
- 所有金额在显示时除以 100 转换为元
- 格式化为两位小数：`(amount / 100).toFixed(2)`

### 为什么使用"分"作为单位？

1. **精度保证：** 避免浮点数计算误差
2. **整数运算：** 数据库和后端计算更高效
3. **行业标准：** 微信支付、支付宝都使用分为单位
4. **易于对接：** 与支付渠道API无缝衔接

## 修复效果

### 订阅记录页面

**修复前：**
- 59900分 → 后端返回 599 → 前端显示 **5.99元** ❌

**修复后：**
- 59900分 → 后端返回 59900 → 前端显示 **599.00元** ✅

### 支付订单页面

**新增功能：**

| 套餐价值 | 实付金额 | 说明 |
|----------|----------|------|
| ¥800.00 | ¥600.00 | 节省了 ¥200.00（残值抵扣或优惠） |
| ¥480.00<br/>省 ¥80.00 | ¥400.00 | 有促销优惠 |
| - | ¥599.00 | 历史订单（无 planValue 数据）|

**管理员可以清晰看到：**
1. 套餐标准价值
2. 用户实际支付金额
3. 节省的金额（促销优惠 + 残值抵扣）
