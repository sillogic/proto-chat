## 功能概述

项目已集成支付宝当面付（扫码支付）功能，用户可以通过扫描二维码完成订阅支付。

**已实现功能：**
- ✅ 支付宝当面付（二维码支付）
- ✅ 支付方式切换（支付宝/微信）
- ✅ 订单创建、查询、关闭
- ✅ 支付回调处理
- ✅ 订阅自动开通
- ✅ 积分自动发放

**支付方式说明：**
- **支付宝**：当前可用，默认选中
- **微信支付**：暂未开通（显示"敬请期待"）

**支付模式：**
- 当前为一次性支付，用户每次续费需要手动支付
- 未来可升级为周期扣款（自动续费）

## 前置要求

### 1. 支付宝企业账号

- ✅ 已完成企业账户注册
- ✅ 已开通网页端支付申请

### 2. 创建应用

1. 登录 [支付宝开放平台](https://open.alipay.com/)
2. 进入：**控制台** → **网页&移动应用**
3. 点击 **"创建应用"**
4. 选择 **"网页应用"** 类型
5. 填写应用信息并提交审核
6. 等待审核通过

### 3. 开通功能

在应用详情中：
1. 进入：**功能列表**
2. 添加 **"当面付"** 功能
3. 签约并等待审核通过

## 配置步骤

### 第一步：生成并配置密钥

#### 1.1 下载密钥生成工具

1. 登录支付宝开放平台
2. 进入：**开发者中心** → **开发工具** → **密钥生成工具**
3. 下载适合你操作系统的工具

#### 1.2 生成密钥对

1. 打开密钥生成工具
2. 选择密钥格式：**PKCS8（Java适用）**
3. 选择密钥长度：**RSA2（2048位）**
4. 点击 **"生成密钥"**
5. 保存生成的密钥对：
   - **应用私钥**（`app_private_key.txt`）
   - **应用公钥**（`app_public_key.txt`）

#### 1.3 上传应用公钥到支付宝

1. 登录支付宝开放平台
2. 进入：**应用详情** → **开发设置** → **接口加签方式（密钥/证书）**
3. 选择 **"公钥"** 模式
4. 粘贴 `app_public_key.txt` 的内容到输入框
5. 点击 **"保存"**

#### 1.4 获取支付宝公钥

上传成功后，支付宝会显示 **"支付宝公钥"**：
1. 点击 **"查看支付宝公钥"**
2. 复制并保存支付宝公钥（不是你的应用公钥！）

---

### 第二步：配置环境变量

在项目根目录的 `.env` 文件中添加以下配置：

```bash
# ============================================================================
# 支付宝支付配置
# ============================================================================

# 支付宝应用 APPID
# 位置：支付宝开放平台 -> 应用详情 -> 应用信息
ALIPAY_APP_ID=2021000000000000

# 应用私钥（RSA2 格式）
# 来源：密钥生成工具生成的 app_private_key.txt
# ⚠️ 需要去掉头尾标记和所有换行符，只保留Base64字符串
ALIPAY_PRIVATE_KEY=MIIEvgIBADANBgkqhkiG9w0BAQEFAASCBKgwggSkAgEAAoIBAQC...

# 支付宝公钥（用于验证签名）
# 来源：支付宝开放平台 -> 应用详情 -> 开发设置 -> 查看支付宝公钥
# ⚠️ 这是支付宝平台的公钥，不是你的应用公钥！
# ⚠️ 需要去掉头尾标记和所有换行符，只保留Base64字符串
ALIPAY_PUBLIC_KEY=MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA...

# 支付宝异步通知地址
# ⚠️ 必须是公网可访问的 HTTPS 地址
ALIPAY_NOTIFY_URL=https://yourdomain.com/api/payment/alipay/notify

# 是否使用沙箱环境（开发测试时可设置为 true）
ALIPAY_SANDBOX=false

# ============================================================================
# 其他必需配置
# ============================================================================

# Cron 任务密钥（用于定时任务验证）
# 生成方式：openssl rand -base64 32
CRON_SECRET=your-random-secret-key-here-please-change-it
```

**⚠️ 密钥格式重要提示：**

**错误示例**（包含头尾标记和换行符）：
```
-----BEGIN PRIVATE KEY-----
MIIEvgIBADANBgkqhkiG9w0BAQEFAASC
BKgwggSkAgEAAoIBAQCxxxxx...
-----END PRIVATE KEY-----
```

**正确示例**（纯Base64字符串）：
```
MIIEvgIBADANBgkqhkiG9w0BAQEFAASCBKgwggSkAgEAAoIBAQCxxxxx...
```

### 第三步：配置授权回调地址

1. 登录支付宝开放平台
2. 进入：**应用详情** → **开发设置** → **授权回调地址**
3. 添加：`https://yourdomain.com/api/payment/alipay/notify`
4. 保存

---

### 第四步：配置服务器（生产环境）

#### 4.1 确保 HTTPS

支付宝要求回调地址必须是 HTTPS，确保你的域名已配置 SSL 证书。

#### 4.2 配置防火墙

确保服务器防火墙允许支付宝服务器的请求访问你的回调接口。

#### 4.3 配置 IP 白名单（可选）

为了安全，建议在支付宝开放平台配置 IP 白名单：
1. 进入：**应用详情** → **开发设置** → **IP白名单**
2. 添加你的服务器公网 IP 地址

## 测试流程

### 方案一：沙箱环境测试（推荐）

#### 1. 获取沙箱配置

1. 登录支付宝开放平台
2. 进入：**开发者中心** → **研发服务** → **沙箱**
3. 获取沙箱应用信息：
   - 沙箱 APPID
   - 沙箱 RSA2 密钥（或生成新的）
   - 沙箱支付宝公钥

#### 2. 配置沙箱环境变量

```bash
ALIPAY_APP_ID=沙箱APPID
ALIPAY_PRIVATE_KEY=沙箱应用私钥
ALIPAY_PUBLIC_KEY=沙箱支付宝公钥
ALIPAY_NOTIFY_URL=https://your-dev-domain.com/api/payment/alipay/notify
ALIPAY_SANDBOX=true
```

#### 3. 使用沙箱账号测试

支付宝沙箱提供测试买家账号：
- 进入沙箱环境页面查看买家账号和密码
- 使用支付宝 App 扫描二维码
- 切换到沙箱环境登录
- 完成支付测试

## 常见问题

### Q1: 提示"验签失败"

**可能原因：**
1. 使用了错误的公钥（应该用支付宝公钥，不是应用公钥）
2. 密钥格式不正确（包含头尾标记或换行符）
3. 未在支付宝平台上传正确的应用公钥

**解决方法：**
1. 确认 `ALIPAY_PUBLIC_KEY` 是支付宝平台提供的公钥
2. 确认密钥格式正确（纯Base64字符串，无头尾和换行）
3. 重新上传应用公钥到支付宝平台

---

### Q2: 提示"应用未开通该功能"

**可能原因：**
1. 未添加"当面付"功能
2. 功能未签约
3. 功能审核未通过

**解决方法：**
1. 检查应用功能列表
2. 确认已签约"当面付"
3. 等待审核通过

---

### Q3: 回调通知未收到

**可能原因：**
1. `ALIPAY_NOTIFY_URL` 不是公网可访问的 HTTPS 地址
2. 服务器防火墙阻止了支付宝的请求
3. 回调接口代码有错误

**解决方法：**
1. 确认回调地址可从公网访问
2. 检查服务器防火墙配置
3. 查看服务器日志获取详细错误信息
4. 使用支付宝提供的"异步通知调试工具"测试

---

### Q4: 二维码无法生成

**可能原因：**
1. 订单金额格式不正确
2. 必填参数缺失
3. 网络连接问题

**解决方法：**
1. 检查订单金额是否正确（单位：元）
2. 查看服务器日志获取详细错误信息
3. 确认网络连接正常

---

### Q5: 沙箱环境扫码后无法支付

**可能原因：**
1. 未使用沙箱买家账号
2. 支付宝 App 未切换到沙箱环境

**解决方法：**
1. 使用支付宝开放平台提供的沙箱买家账号
2. 在支付宝 App 中切换到沙箱环境：
   - 我的 → 设置 → 关于 → 连续点击版本号 10 次
   - 进入开发者模式
   - 切换到沙箱环境

## 技术细节

### 支付流程

```
用户点击订阅
    ↓
选择支付方式（支付宝）
    ↓
前端调用 payment.createOrder (tRPC)
    ↓
后端生成订单号
    ↓
调用支付宝 alipay.trade.precreate API
    ↓
获取二维码字符串
    ↓
前端显示二维码
    ↓
用户扫码支付
    ↓
支付宝回调 POST /api/payment/alipay/notify
    ↓
验证签名 → 检查金额 → 幂等性检查
    ↓
数据库事务更新：
  - 订单状态
  - 用户订阅
  - 积分余额
  - 订阅历史
    ↓
返回 success 给支付宝
    ↓
前端轮询检测到支付成功
    ↓
显示成功页面并刷新
```

### 重要文件

**后端：**
- `src/server/modules/payment/channels/alipay-precreate.ts` - 支付宝支付通道
- `src/server/modules/payment/index.ts` - 支付服务主类
- `src/app/(backend)/api/payment/alipay/notify/route.ts` - 支付回调处理

**前端：**
- `src/features/Payment/PaymentModal.tsx` - 支付弹窗
- `src/app/[variants]/(main)/subscription/plans/features/PlanCard.tsx` - 订阅方案卡片

**配置：**
- `.env` - 环境变量配置
- `.env.alipay.example` - 配置示例
